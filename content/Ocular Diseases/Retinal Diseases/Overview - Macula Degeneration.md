# Description
---
Damage to the Macula 
Classified into Non-Exudative AMD and Exudative AMD
### Non-Exudative AMD
- Previously referred to as “dry AMD”
- Can be further classified as early, intermediate, and advanced stage
### Exudative AMD
- Previous referred to as “wet AMD”
- Can be further classified as Type 1, Type 2 or Type 3 choroidal neovascular membranes (CNV)
- The updated nomenclature for this is now 'Macular Neovascularisation’ (MNV)
