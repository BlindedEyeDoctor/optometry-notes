# Description
Burning = **tear film instability** or **surface inflammation**.
# Diagnostic Testing 
- Presentation
	- PX reports a burning sensation
- Recommended Tests
	- Biomicroscopy
		- Assess cornea, conjunctiva, eyelid, eyelid margin perform eyelid inversion
		- See Below for Associated Symptoms
	- Dry Eye Testing
		- Assess tear film integrity
		- See Below for Associated Symptoms
# Differential Diagnosis
- **Dry Eye Disease**
- **Meibomian Gland Dysfunction (MGD)**
- **Blepharitis**
- **Conjunctivitis (viral/bacterial/allergic)**
- **Chemical/Irritant Exposure**
- **Contact Lens Overwear**
- **Corneal SPK (superficial punctate keratitis)**
# Associated Symptoms
- Stinging
- Fluctuating blur
- Photophobia (if corneal epithelium compromised)
- Reflex tearing
- Redness
- Grittiness
