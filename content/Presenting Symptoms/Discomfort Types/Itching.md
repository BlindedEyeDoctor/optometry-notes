# Description
Itching = **allergy** until proven otherwise.
# Diagnostic Testing 
- Presentation
	- PX reports itchiness in eye
- Recommended Tests
	- Biomicroscopy
		- Assess cornea, conjunctiva, eyelid, eyelid margin perform eyelid inversion
		- See Below for Associated Symptoms
# Differential Diagnosis
- **Allergic Conjunctivitis**
- **Vernal Keratoconjunctivitis (VKC)**
- **Atopic Keratoconjunctivitis (AKC)**
- **Blepharitis (anterior)**
- **Dry Eye Disease** (mild itching possible)
- **Contact Dermatitis** (cosmetics, soaps)
# Associated Symptoms
- Stringy/mucoid discharge
- Papillae
- Lid swelling
- Rubbing
- Seasonal pattern
- Fluctuating blur (tear film instability)
