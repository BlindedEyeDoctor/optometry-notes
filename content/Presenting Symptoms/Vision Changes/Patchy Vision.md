# **Associated Diseases**

**Mechanisms:** sectoral retinal ischemia, macular edema, branch occlusions

### Retinal Occlusions

- **BRVO** (sectoral hemorrhages → patchy loss)
    
- **BRAO** (sectoral pale retina → patchy field loss)
    
- **CRVO** (patchy hemorrhages + macular involvement)
    

### Macular / Edema

- DME
    
- Macular ischemia
    
- CSR (patchy distortion)
    

### Retinal Disease

- Vasculitis
    
- Peripheral retinal ischemia
