# Description
Decline of ability to see color. 
# **Associated Diseases**

**Mechanisms:** optic nerve, severe macular disease

### Optic Nerve

- Optic neuritis
    
- AION
    
- Glaucoma (advanced)
    
- Toxic optic neuropathy
    
- Compressive neuropathy
    

### Macular

- Severe AMD
    
- Macular edema (DME, CRVO)
    
- CRAO (foveal ischemia → desaturation)
