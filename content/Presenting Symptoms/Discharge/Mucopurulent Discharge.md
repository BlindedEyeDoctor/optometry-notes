# Description 
**Mixed mucus + pus** → thick, yellow‑white discharge. Combination of **bacterial infection + mucous irritation**.
# Associated Symptoms
- Redness
- Crusting
- Lids stuck shut
- Follicles (chlamydia)
- Preauricular node (viral)
- Tender medial canthus (dacryocystitis)
# Diagnostic Testing 
- Presentation
	- PX reports crusting or more sleep in eyes
	- PX reports eyes glued together
- Recommended Tests
	- Biomicroscopy
		- Assess cornea, conjunctiva, eyelid, eyelid margin perform eyelid inversion
		- See Below for Associated Symptoms
# Differential Diagnosis
- **Bacterial Conjunctivitis (moderate)** Sticky, yellow/white discharge; lids glued shut.
- **Chlamydial Conjunctivitis** Chronic mucopurulent discharge + follicles. (Supported by mucous discharge in infectious conjunctivitis)
- **Severe Viral Conjunctivitis (adenoviral)** Can produce mucous + white/yellow discharge.
- **Blepharitis** Crusty mucopurulent discharge on waking.
- **Dacryocystitis** Sticky mucous/pus reflux from punctum.
